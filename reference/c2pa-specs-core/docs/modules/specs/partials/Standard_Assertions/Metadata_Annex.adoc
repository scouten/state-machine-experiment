== Implementation Details for `c2pa.metadata`

The `c2pa.metadata` assertion shall only contain the subset of schemas and their fields as described below. However xref:_common_requirements[custom metadata assertions] may contain any values from these or other schemas.

NOTE: A machine readable list of all the valid schemas and their fields can be found on the https://spec.c2pa.org/specifications/specifications/2.3/specs/_attachments/C2PA_Schemas.zip[C2PA Specification Website].

The values present in a `c2pa.metadata` assertion may be unique to the metadata assertion or they may be taken from the standard "metadata blocks" of the asset format. In either case, they shall be serialized according to the rules of {xmp-json} as described xref:_common_requirements[here].
